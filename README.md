# Computer Networks

BMSTU IU7, semester 7.

Cisco Packet Tracer labs: switching, routing and edge services, each with the
saved topology and the device configurations it was built from.

## Structure

| Path                   | Topic                                        |
|------------------------|----------------------------------------------|
| `lab-01-basic-config`  | Basic switch and router configuration        |
| `lab-02-vlan`          | VLAN segmentation and trunking               |
| `lab-03-routing`       | OSPF and BGP, with per-device configs        |
| `lab-04-acl`           | Access control lists                         |
| `lab-05-nat`           | NAT and port forwarding                      |
| `tasks`                | Assignments                                  |
| `topologies`           | Topology diagrams                            |

Each lab holds a `.pkt` file for Packet Tracer; `lab-03-routing` and
`lab-04-acl` also keep the running configuration of every device as text, so
the setup is readable without opening the simulator.

## Stack

Cisco IOS, Packet Tracer, OSPF, BGP, VLAN, ACL, NAT
